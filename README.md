# spdx-cpp-model

![Apache-2.0 license](https://img.shields.io/github/license/spdx/spdx-cpp-model)

`spdx-cpp-model` is a C++ library for working with the SPDX 3 data model.

All bindings in this repository are auto-generated from the RDF and SHACL
definitions of the [SPDX specification version 3][spdx-spec] using
[shacl2code].

[spdx-spec]: https://spdx.org/specifications
[shacl2code]: https://github.com/JPEWdev/shacl2code
